# Lead Management CRM

A full-stack CRM application built with React, Node.js, Express, and MongoDB.

## Features

* User Registration
* User Login
* JWT Authentication
* Protected Routes
* Create Leads
* Edit Leads
* Delete Leads
* Search Leads
* Status Filter
* Pagination
* Dashboard Statistics

## Tech Stack

### Frontend

* React
* React Router
* Axios
* Tailwind CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT

## Installation

### Clone Repository

git clone YOUR_GITHUB_REPOSITORY_URL

### Backend Setup

cd backend

npm install

Create .env:

PORT=8000

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET

Run backend:

npm run dev

### Frontend Setup

cd frontend

npm install

npm run dev
